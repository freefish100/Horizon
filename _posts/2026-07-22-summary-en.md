## [Tao Digests Counterexample to Jacobian Conjecture](https://terrytao.wordpress.com/2026/07/21/a-digestion-of-the-jacobian-conjecture-counterexample/) ⭐️ 9.0/10

Terry Tao published a detailed digest of a counterexample to the Jacobian conjecture, announced by Levent Alpöge on July 19, 2026, which disproves the conjecture in dimensions three and higher. This potential resolution of a decades-old open problem in algebraic geometry could reshape the understanding of polynomial maps and their inverses, with implications for algebraic geometry and symbolic computation. The counterexample is a polynomial map in three variables of degree seven whose Jacobian determinant is a nonzero constant, yet the map is not invertible over ℂ. Tao's digestion reveals massive cancellations that cause the Jacobian to collapse to a constant.

hackernews · jeremyscanvic · Jul 21, 21:09 · [Discussion](https://news.ycombinator.com/item?id=48998362)

**Background**: The Jacobian conjecture states that any polynomial map from ℂⁿ to ℂⁿ with a nonzero constant Jacobian determinant must have a polynomial inverse. It is known to be true in one dimension but remained open for higher dimensions until this counterexample. Tao's post provides an algebraic exposition accessible to mathematicians.

## [High Accuracy Masks Failure in Federated Learning](https://www.reddit.com/r/MachineLearning/comments/1v32mfs/my_federated_learning_project_just_showed_that/) ⭐️ 8.0/10

A federated learning project using CICIDS2017 dataset shows that global accuracy of 96% can completely hide a model missing every single attack in a minority class (Web Attacks) due to extreme data imbalance across silos. This demonstrates the 'accuracy paradox' in a practical federated learning setting, urging practitioners to look beyond global metrics. It also shows that aggregation method choice (e.g., FedNova) significantly impacts minority class detection, which is critical for security-sensitive applications. FedAvg achieved ~96% global accuracy but had 0.00 recall on attacks in the minority silo, while FedNova maintained high 90s accuracy across all silos. Even the centralized baseline showed extreme instability, with minority silo accuracy varying from 57% to 99.5% across random seeds.

reddit · r/MachineLearning · /u/Initial-Street6388 · Jul 22, 02:08

**Background**: Federated learning trains models across decentralized data silos without sharing raw data. When data is highly imbalanced across silos, global accuracy can be misleading because it averages performance over many clients, potentially hiding failures on rare but critical classes. This phenomenon is known as the accuracy paradox.

## [Cloudflare Internal DNS Service Goes Live](https://blog.cloudflare.com/internal-dns/) ⭐️ 8.0/10

Cloudflare announced the general availability of its Internal DNS service on July 20, 2026, which provides authoritative and recursive DNS resolution for enterprise private networks and integrates with its Zero Trust platform. This service unifies public and private DNS management on a single global network, simplifying split-horizon DNS configuration and extending Zero Trust policies to the DNS layer, which reduces complexity and improves security for enterprise networks. Existing Cloudflare Gateway customers can enable Internal DNS at no extra cost. Administrators can use DNS Views to define resolver policies that control which internal IP addresses different users and devices can resolve, and deployment is supported via API, Terraform, and Cloudflare WAN.

telegram · zaihuapd · Jul 21, 03:49

**Background**: Split-horizon DNS (also called split-view DNS) is a technique that provides different DNS responses based on the source of the request, allowing internal and external users to resolve different IP addresses for the same domain name. This is commonly used by enterprises to keep internal network information private. Cloudflare Gateway is a cloud-native Secure Web Gateway that inspects and filters DNS, HTTP, and network traffic as part of the Cloudflare One Zero Trust platform.
