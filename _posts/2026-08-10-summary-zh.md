## [利用 Evo 1 和 Evo 2 基因组语言模型生成可存活的噬菌体基因组](https://www.reddit.com/r/MachineLearning/comments/1vjj4pr/r_generative_design_of_novel_bacteriophages_with/) ⭐️ 9.0/10

研究人员利用 Evo 1 和 Evo 2 基因组语言模型，以裂解性噬菌体ΦX174 为模板生成了完整的噬菌体基因组，并实验验证了其中 16 个 AI 设计的噬菌体具有活性。这是首次实现可存活噬菌体基因组的生成式设计。 这项工作表明，基因组规模的语言模型能够产生功能性生物序列，为 AI 驱动的合成生物学以及定制噬菌体设计开辟了新的途径，在抗菌治疗和生物技术领域具有潜在应用。它也将生成式 AI 推进到了全基因组工程的前沿。 设计以被广泛研究的裂解性噬菌体ΦX174 为模板，生成的基因组表现出真实的遗传结构和预期的宿主趋向性。这 16 个可存活的噬菌体显示出显著的进化新颖性，意味着它们并非模板序列的简单近似拷贝。

reddit · r/MachineLearning · /u/moschles · 8月9日 07:11

**背景**: 基因组语言模型将自然语言处理技术应用于基因组序列，把 DNA 视为一种可以学习和生成的语言。Evo 1 和 Evo 2 是在大规模基因组数据集上训练的前沿基因组语言模型。噬菌体是感染细菌的病毒，ΦX174 是一种小型、特征明确的裂解性噬菌体，常被用作模式生物。这项研究测试了生成式语言模型能否设计完整的功能基因组，而不仅仅是个别的遗传部件。

## [GitHub Models 正式退役，CI/CD 中的 LLM 工作流受影响](https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/#atom-everything) ⭐️ 8.0/10

GitHub Models 已于 2026 年 7 月 30 日正式退役，其 playground、模型目录、推理 API 和 BYOK 功能已对所有客户停止服务。Simon Willison 的 GitHub Actions 工作流因此报错，他已改用带月度限额的 OpenAI API 密钥并使用 GPT-5.6 Luna 生成摘要。 此事意义重大，因为 GitHub Models 为多个 LLM 提供商提供了统一 API，并让 GitHub Actions 能直接利用已有的 GitHub API 密钥免费执行提示词，是持续 AI 工作流的重要基础。它的退役打乱了这类自动化流程，开发者不得不迁移到其他服务商，可能带来更高的成本和复杂性。 退役公告于 2026 年 7 月 30 日发布在 GitHub changelog 中，连“退役停电（brownout）”提示都滞后于实际完成时间。Willison 推测，编码代理（coding agent）模式让免费或补贴 token 的成本变得难以承受，但 GitHub 官方并未说明原因。

rss · Simon Willison · 8月9日 22:48

**背景**: GitHub Models 是 GitHub 推出的一个 AI 实验平台，提供网页 playground 和统一的推理 API，可访问 OpenAI、DeepSeek、Meta、Microsoft、xAI 等多家提供商的模型。其最大优势是 GitHub Actions 可以直接使用仓库中已有的 GitHub API 密钥调用大模型，从而支持持续 AI 模式——让后台代理像 CI/CD 自动化规则型任务一样，在 CI 流程中处理需要推理的任务。

## [全球最大单体 AI 算力设施在内蒙古乌兰察布投产](https://www.globaltimes.cn/page/202608/1367666.shtml) ⭐️ 8.0/10

8 月 6 日，远景科技集团宣布“远景乌兰察布星河基地”正式投产。该基地建筑面积 12 万平方米，支持百万 GPU 并行计算，规划总容量 2GW，绿电占比超 80%，是全球最大的单体 AI 算力设施。 这一里程碑标志着 AI 基础设施的大规模扩张，尤其对中国国产算力生态意义重大。该基地距北京传输仅 4.2 毫秒且电价更低，使其成为大规模 AI 模型训练和 Token 产出的战略枢纽。 乌兰察布是国家“东数西算”八大节点之一，该基地是远景“戈壁使命”计划的首个旗舰项目，旨在为国产算力集群提供可复制方案。此前，华为、阿里巴巴、苹果、快手等企业已在此布局算力设施。

telegram · zaihuapd · 8月9日 05:06

**背景**: “东数西算”是中国的一项国家工程，旨在西部资源丰富的地区建设数据中心，处理东部经济活动产生的数据。该设施强调 Token 产出能力，反映了行业正逐步转向用“每瓦 Token 数”来衡量 AI 数据中心效率，而非传统电力指标。超过 80%的绿电占比和靠近北京的地理位置，使乌兰察布成为新一代 AI 基础设施的理想选址。

## [马斯克公布月球机器人建厂造 AI 卫星计划](https://finance.yahoo.com/technology/articles/pure-insanity-elon-musk-details-173635969.html) ⭐️ 8.0/10

在 SpaceX 首次公开财报电话会议上，马斯克公布了一项月球自动化工厂计划：用 Starship 火箭运送设备，让机器人从月球土壤中提取矿物，大规模生产 AI 计算卫星，成品通过电磁“质量驱动器”从月面直接发射入轨。 这一前瞻性计划若实现，将利用月球资源和电磁弹射替代从地球发射火箭，大幅降低卫星入轨成本。届时 SpaceX 有望占据月球工业化和太空制造的核心位置，深刻影响太空经济与 AI 基础设施的发展。 该计划依赖原位资源利用（ISRU）技术，从月球表土中提取铝、钛、硅等材料，但月尘磨损性强、每 14 天昼夜交替一次，技术挑战很大。SpaceX 前副总裁 Jim Cantrell 称该计划“纯属疯狂”，但认为马斯克能够实现；业界普遍认可其技术可行性，但提醒马斯克的时间表通常过于乐观。
